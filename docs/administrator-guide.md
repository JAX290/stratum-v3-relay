# 管理员操作指南

本指南面向日常值守和维护人员。功能概览见[项目首页](../README.md#功能说明)，安装及组件排障见[部署与维护指南](deployment-guide.md)。

## 选择访问入口

- **查看生产状态**：打开 HTTPS 状态域名，使用值守账号密码登录，无需 Tailscale。此入口只读。
- **配置矿池、接入客户端、管理矿场**：连接 Tailscale，打开管理面板地址。
- **查看 VPS 日志原因与处理建议**：在管理面板打开“日志 → 运维问题中心”。需要技术协助时展开原始日志。

管理面板地址由部署脚本和 `tailscale serve status` 输出；HTTPS 状态域名由管理员配置。两者用途不同，不能互相替代。

## 日常值守

1. 查看总状态和异常提示，确认是否存在矿场离线、服务异常或线路问题。
2. 查看矿场最近心跳、客户端版本、矿机数和连接数。
3. 查看 Share 接受、拒绝情况。仅有连接不代表矿机已经正常提交计算结果。
4. 有异常时记录发生时间、矿场名称和页面提示，交由管理员处理。公网只读页面不提供修改或修复按钮。
5. 管理员在 Tailscale 面板查看“日志”页的中文处理建议，再按需要核对服务和原始日志。

VPS 自动恢复只处理系统已定义的服务异常，不等于能自动解决所有网络、矿池、电脑或配置问题。Windows 客户端的“一键诊断”用于检查矿场端网络、端口和主备 VPS，不能代替 VPS 管理权限。

## 新增矿场或值守电脑

入口：**Tailscale 管理面板 → 设置 → 客户端接入资料**。

1. 在“新增矿场 / 新增客户端”填写名称，例如“云南一号矿场（电脑1）”。
2. 点击“新增矿场并生成接入密钥”。编号和独立密钥由系统生成。
3. 在新增行复制共享密钥；本页同时提供 VPS 地址、TLS 端口和证书 SHA-256 指纹。
4. 将这些资料填写到新电脑的木林森中转，对应到正确的主 VPS 或备用 VPS。
5. 运行连接测试，成功后保存并启动中转。
6. 在矿场总览确认心跳、矿机状态和 Share。首次接入前显示“等待首次连接”。

每台值守电脑建议使用独立密钥。共用密钥会合并矿场统计，并使删除该密钥的影响扩大到所有使用者。两台 VPS 分别管理密钥，需要分别新增并填写各自接入资料；线路同步不会代替这一步。

## 修改矿场名称

1. 在接入资料页找到目标行，点击名称下方的“编辑矿场名称”。
2. 填写名称并保存。
3. 刷新管理总览或 HTTPS 只读面板，核对显示名称。

修改名称保留原编号和密钥，不需要重新配置客户端。

## 删除不用的矿场

**删除可能导致矿场中转掉线。先停用对应电脑，或完成迁移并确认矿机已在新客户端正常提交 Share。**

1. 在接入资料页找到目标行，点击“删除矿场”。点击此入口只打开确认页，不执行删除。
2. 核对矿场名称、编号、当前连接数、最近来源和最近连接时间。
3. 手动完整输入矿场名称。
4. 勾选“我已确认该矿场已停用或迁移，并了解原密钥将无法重新连接”。
5. 点击“确认删除该矿场及接入密钥”。不确定时选择“取消，保留矿场”。

确认页有效期为 5 分钟；名称或密钥发生变化后需要重新确认。删除结果如下：

- 原密钥不能建立新连接或重连；已有连接可能暂时继续，不代表后续仍能使用。
- 不重启整个中转服务，不删除其他矿场的配置，也不自动删除另一台 VPS 的接入资料。
- 操作记入审计日志，不记录密钥。保存前保留一份仅 root 可读的配置恢复副本。
- 重新新增会生成新密钥，旧电脑必须重新填写资料。
- 最后一个矿场也可删除；加密入口保持运行，等待重新添加客户端。

误删后应联系维护人员处理配置恢复，或重新新增并更新客户端资料；不要反复重启整套服务。

## 找回连接资料与修改密码

- **重装或更换 Windows 电脑**：通过 Tailscale 打开接入资料页，核对对应矿场后复制资料。密钥默认隐藏，查看或复制记入审计，查看后 60 秒自动隐藏。
- **修改 HTTPS 值守账号或密码**：由维护人员在 VPS 重新运行状态网站安装脚本并传入 `--reset-login`，详见[HTTPS 只读面板配置](deployment-guide.md#54-不使用-tailscale-的-https-只读面板)。
- **Tailscale 不可用**：可使用 SSH 隧道和预先设置的应急密码；客户端接入资料仍要求通过 Tailscale 访问。

共享密钥、密码、Webhook 和证书私钥不要发到公开群、Issue 或仓库中。证书指纹是公开校验信息，与共享密钥不同。

## 常用词说明

| 名称 | 含义 |
| --- | --- |
| 矿机数 | 按局域网 IP 识别的矿机数量；同一台矿机可能建立多条连接 |
| 连接数 | 当前中转连接数量，与矿机数不同 |
| Worker | 矿池账号下的矿工标识，不一定与矿场名称相同 |
| Share | 矿机提交给矿池的计算结果，可接受或被拒绝 |
| 心跳 | 客户端定期上报的状态，用于判断最近是否在线 |
| 证书指纹 | 客户端用于确认 VPS 证书的公开校验值 |
| 共享密钥 | 允许客户端接入对应 VPS 的秘密凭据 |
