# 客户端目录使用约定

用户于 2026-09-21 明确要求：client 目录保存所有历史正式版、兼容版和测试版 EXE，以便随时回顾。不得因版本旧而删除或移走；备份不能替代原目录中的版本保留。

外层保留各版本 EXE 和校验文件，源码、脚本、图标、证书及开发说明集中放入 src 子目录。本次误清理的历史程序已全部恢复，并逐个核对 SHA-256。

以后每次正式发布，将最终签名桌面 EXE 原样保存到 client 目录，命名为“木林森中转<版本>正式版.exe”；服务版同时保存为“木林森中转服务<版本>.exe”。每个 EXE 均保留同名 .sha256 文件，并核对其与 GitHub 附件摘要一致。禁止覆盖其他版本。安装脚本、证书工具和统一校验清单归档到 `src/releases/<版本>`。

构建入口为 src/build.ps1，默认输出仍是 client 目录。测试入口为 src/test-client.ps1，测试产物继续放在独立临时目录。signing 中的公开证书和安装脚本也位于 src 下；私钥不随目录迁移。

源码不是运行配置文件，保留用于后续开发。实际用户配置继续使用原来的本地应用数据目录，本次未改动。
