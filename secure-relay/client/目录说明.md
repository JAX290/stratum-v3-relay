# 客户端目录使用约定

用户于 2026-09-21 指定：今后发布的正式 EXE 均在本目录保存，命名为 `木林森中转<版本>正式版.exe`，旁边保留同名 `.sha256` 校验文件。

正式发布可以从干净提交在临时目录构建和签名，但发布完成前必须把已签名的最终 EXE 原样复制到本目录，并核对本地文件与 GitHub 附件 SHA-256 一致。不要重新编译或修改已签名文件。`build.ps1` 默认输出位置就是本目录；测试继续使用独立临时目录。

源码、测试脚本、架构说明、图标源文件和 `signing` 中的公开证书及安装脚本均属于必要资料，应保留。EXE 和校验文件本地保存，发布到 GitHub Releases，不再将新二进制文件加入 Git 源码。

清理旧版本前，先在上一级 `local-archives` 目录打包备份，并核对每个文件的 SHA-256。运行中的程序不强制关闭或删除，待维护停机后再处理。回退用的历史正式版可以从备份中恢复。

2026-09-21 已将 12 个旧版／测试程序打包备份，并从本目录移除其中 11 个；2.2.1 正式版因正在运行而保留。当前发布版为 2.2.2。
